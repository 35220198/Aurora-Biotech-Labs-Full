# Aurora Biotech Labs Portal

A responsive web portal for a clinical-stage biopharmaceutical leader specializing in genetic therapeutics, precision oncology, and molecular bioinformatics.

## 🧬 Core Architecture & Pipelines
The portal showcases three therapeutic pipelines:
* **ABX-CRISPR-04 (Phase III):** Next-generation gene editing targeting rare hereditary disorders via CRISPR-Cas12 vectors (FDA Fast Track).
* **ABX-IMMUNO-9 (Phase II):** Precision oncology platform generating personalized mRNA tumor vaccines for T-cell responses.
* **ABX-NEURO-12 (Pre-Clinical):** Small molecule inhibitors targeting protein aggregation in early-stage cognitive conditions.

## 🛠️ Infrastructure Capabilities
* **Sequencing Hub:** Decodes 5,000 whole genomes weekly via high-throughput sequencers.
* **Cryogenic Repository:** Automated liquid nitrogen storage for 2+ million cellular samples.
* **GMP Cleanrooms:** ISO Class 5 certified aseptic suites for clinical-grade mRNA vectors.
* **Supercomputing Array:** Machine learning models for molecular docking simulations.

## 📂 Codebase Overview
* **`index.html`:** Responsive UI showcasing research, facilities, leadership, and partnership intake forms.
* **`style.css`:** Modern stylesheet featuring a dark-themed sticky nav-bar, flex layouts, and CSS variables.
* **`script.js`:** Handles dynamic modal dossiers, client-side category filtering, and mobile menu toggles.
